# Blockchain_BB101COL

Repositorio del equipo para las actividades semanales del bootcamp **Blockchain Builders 101**.

## Estructura

- `docs/semana1/` — Problem Briefs individuales (Fase 1) y la elección final del equipo (Fase 2).

## Cómo participar — Semana 1, Fase 1

1. Crea tu propio archivo en `docs/semana1/TuNombre.md` (ej. `MariaPaula.md`).
2. Complétalo con estas secciones:
   - **El problema** (una sola frase, sin mencionar blockchain)
   - **¿Quién lo sufre?**
   - **¿Cómo se resuelve hoy y qué cuesta?**
   - **¿Por qué creo que blockchain podría aportar?** (hipótesis, no certeza)
3. Sube tu archivo con tu propio commit (no lo mezcles con el de otro integrante), para que quede un commit por persona en el historial.

## Fase 2

Cuando todas las propuestas individuales estén subidas, el equipo las debate y elige una. La decisión final, junto con el motivo de la elección y por qué se descartaron las demás, también se registra en `docs/semana1/`.
